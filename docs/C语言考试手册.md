## 脚手架介绍

> 手册版本：v1.4 · 配套脚手架：v0.4.0  
> 开源仓库：[Annouimo/c-exam-kit](https://github.com/Annouimo/c-exam-kit) · [版本下载与更新](https://github.com/Annouimo/c-exam-kit/releases)

**下载建议：优先在上述 Release 页面选择与你的操作系统和CPU架构对应的编译成品，解压后运行。若成品无法运行或有兼容问题，可下载单文件源代码 `c_template_builder.c` 自行编译；编译方法见仓库 README。**

**C 语言脚手架**是一款离线代码装配工具：按题目选择输入输出方式和所需函数，生成方便修改的 C 代码框架。

相比常见的“查资料、复制模板、手动拼接”，它主要改进了这些地方：

- **从题目输入方式出发**：提供单组、T 组、读到输入结束、遇指定值停止、操作指令、文本文件等程序外框。
- **按需组合功能**：一次选择多个函数组件，只生成本题需要的内容。而且每种功能都可以跳过，例如如果不需要所需函数，只想要输入输出模板，可以直接跳过组合函数部分。
- **自动补齐依赖**：带入所需头文件、结构体、宏和辅助函数，共用定义自动去重。
- **支持接入已有程序**：可只生成函数、不生成 `main`，适合已有代码或 OJ 函数填空题。
- **提供常用代码片段**：数组和矩阵读入、分隔输出、排序分组等重复操作也能按需加入。
- **减少现场修改**：按需配置数组容量、整数类型等参数，相关代码同步调整。
- **代码直接送到编辑器**：默认复制纯源码到剪贴板，也可保存为文件。
- **资料分工更清楚**：考试手册保留简短目录，程序提供本次说明，全量手册供详细查阅。

它保留了传统板子的可读、可改和可复用特点，同时减少查找、补依赖与拼接代码的重复劳动。**题意分析、函数调用和最终输入输出仍由使用者完成。**

### 格式化输入输出：printf 与 scanf

常用说明符示例：`%19s` 限制最多读 19 个字符，防止数组越界；`%s` 遇到空白字符停止。

```c
printf("%d %i %u %o %x %X %c %s %f %%\n",
       -42, 42, 42u, 42, 42, 42, 'A', "hi",
       3.14);
// 输出：-42 42 42 52 2a 2A A hi 3.140000 %
```

```c
// 输入：10 3.14 hello
int a;
double x;
char s[20];
int r = scanf("%d %lf %19s", &a, &x, s);
```

`printf` 专有 flags、width、precision 示例：`5` 是最小字段宽度；`-` 左对齐；`0` 用前导零填充；`+` 强制显示正负号；`.3` 对 `f` 表示小数点后 3 位；`.2s` 表示字符串最多输出 2 个字符。

```c
printf("[%5d][%-5d][%05d][%+d][%8.3f][%.2s]\n",
       42, 42, 42, 42, 3.14159, "abcdef");
// 输出：[   42][42   ][00042][+42][   3.142][ab]
```

`scanf` 的 width 是“最多读取字符数”示例：

```c
// 输入：20261110
int y, m, d;
scanf("%4d%2d%2d", &y, &m, &d);
```

### 空格与空行问题

- 读单词、数字、跳过空白读字符：`scanf`；字符写 `" %c"`。
- 跳过前导空白，读一行非空内容：`char s[100]; scanf(" %99[^\n]",s);`，保留内部空格，但不跨行。
- 需要保留行首空格或读取空行：`fgets`，注意它保留末尾换行。

### bsearch 和 qsort 使用示例

```c
#include <stdio.h>
#include <stdlib.h>

int cmp_int(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y); /* 升序 */
}
// 注：上面这个函数可在脚手架的“给整数数组按数值排序”组件中找到

void demo_qsort_bsearch(void) {
    int a[] = {5, 2, 9, 1, 5, 6};
    size_t n = sizeof a / sizeof a[0];
    int key = 5;

    qsort(a, n, sizeof a[0], cmp_int); /* 先排序 */
    int *p = (int *)bsearch(&key, a, n, sizeof a[0], cmp_int);
    if (p) printf("found %d at index %ld\n", *p, p - a);
    else printf("not found\n");
}
```

说明：`bsearch` 要求数组已按同一比较函数升序排序；比较函数返回负数/0/正数。
