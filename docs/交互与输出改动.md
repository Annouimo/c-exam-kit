# v0.6.2 交互与输出整理

发布版本：脚手架0.6.2、手册1.6.2。

- 第一步选择程序流程，只追加当前流程需要的读法；新增分阶段流程、EOF数组与双值停止。
- 取消独立的main内片段必经页；确认页用o按需补充处理/输出。
- 没有参数时跳过空配置页；启动署名只显示一次，结果页按本次所选内容显示用法。
- 确认页回车复制精简注释、1复制无注释、2复制完整注释；s保存并直接选模式，r返回修改，q取消。返回修改后回车保留已有函数。
- 恢复顶部名称、版本、作者与开源链接，元数据和头部模板分开维护。
- 无注释、精简、完整三种模式由模板注释槽直接生成，默认精简；减少空白，按依赖引入头文件。
- PDF去掉章节特定分页；表格允许跨行分页并重复表头，标题带住必要开头，列表首尾避免落单；最后短章节按高度整体放置；新增布局报告与扩容压力检查。

自定义读法与字段仍需人工补齐；仅提供脚手架，不自动调用算法或分析题意。旧的低频读入片段保留在全量手册中，避免为其增加常规交互。
