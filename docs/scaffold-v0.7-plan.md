# Scaffold v0.7.0 迁移与验收清单（开发分支）

> 状态：第一阶段，基线冻结与迁移规划。此文件不是已实现功能列表。主分支及 v0.6.4 发布物保持不变。

## 定位与边界

面向 C 初学者的离线、单文件、普通 C 代码装配工具。继续区分：① 输入输出骨架；② 函数组件；③ 可选 main 片段。保留现有四阶段交互和默认复制／可选保存。**不移植 Toolbox 的 String、Vector、Map 等对象接口**；不增加联网、Python 运行时或题目自动求解。

## 已有基线

- catalog/catalog.json 当前版本：0.6.4。
- 九个函数分类、47 个函数组件、11 种程序流程（17 种具体骨架）、8 个 main 片段。
- 生成代码允许用户修改 TODO；需要兼容 C99、常见 GCC/Clang/MinGW。
- 不直接修改既有 release 或 main；新功能在此分支验证后再讨论合并。

## 第二阶段：原有接口审核

- [ ] 字符串：容量检查、空模式、重叠删除、终止符、反复删除与多模式整体删除语义。
- [ ] 排序：比较器避免相减溢出；结构体多关键字排序同时给出 qsort 调用示例。
- [ ] 数组：连续段和前缀和下标约定明确；long long 累加，必要时检查溢出。
- [ ] 高精度：统一内部辅助函数、符号、容量和除零处理；不破坏既有调用方式。
- [ ] 数学：整数幂、阶乘、浮点比较和负零边界。
- [ ] 复数、日期、时间：核对输入与输出的格式语义。

## 第四阶段：验收矩阵

| 场景 | 必须验证 |
| --- | --- |
| 空白 main / 仅函数 | 生成后可编译；仅函数不附加 main |
| EOF / 哨兵 / T 组 | 正常结束、空输入、末行无换行、无多读 |
| 字符／整行输入 | 空行、前导空格、数字与 fgets 混用 |
| 排序 | 多关键字、相等关键字、INT_MIN/INT_MAX |
| 字符串 | 空串、边界容量、重叠匹配、删除后新匹配 |
| 位操作 | 0、最高位、移位 0 和整个位宽 |
| 前缀和／差分 | 单元素、区间端点、负数、long long |
| 生成组合 | 单组件、典型多组件组合、依赖去重 |
| 发布 | 单文件生成器可独立编译运行；离线；旧 Windows 环境无 tmpfile 依赖 |

## 课程题目验证原则

以 C1–C8、E1–E7、SP 的题解为需求样本。逐题记录「可直接用／需改少量代码／算法需手写／题目限制不适用」；选择代表题编译并验证输出。**不能把“题型能表达”当成“已通过 OJ”。**
